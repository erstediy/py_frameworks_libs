# Платёжная система

Оплата и возврат через ЮKassa, подписки и уведомления в Telegram.
Сделано на Python, Flask и SQLite.

## Запуск

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

В `.env` нужно указать ключи тестового магазина, токен Telegram-бота и ID чата.

```powershell
.\.venv\Scripts\python.exe main.py
```

Страница приложения: http://127.0.0.1:5000

## Проверка

Для провреки можно использовать тестовые карты ЮKassa:

- `5555 5555 5555 4444` — успешная оплата и автоплатёж.
- `5555 5555 5555 4600` — недостаточно средств.
- `5555 5555 5555 4642` — первая оплата проходит, автоплатёж отклоняется.

После отказа автоплатежа повтор через сутки, если снова отказ — подписка
приостанавливается. Приложение должно быть запущено, чтобы автоплатежи работали.
Возврат платежа и отмена подписки делаются отдельно.

На форме ЮKassa после отказа карты платёж может оставаться в ожидании. Уведомление
об отказе приходит после того, как ЮKassa отменит сам платёж.

Запуск тестов:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
```
