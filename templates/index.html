Как это работает

Одна страница для всех операций

  1. Создайте платёж и завершите оплату на странице ЮKassa.
  2. Приложение проверит результат и отправит статус в Telegram. При отказе в сообщении будет причина.
  3. Для подписки способ оплаты сохраняется в ЮKassa, а следующие списания выполняются автоматически.

Для проверки статусов и выполнения автоплатежей приложение должно быть запущено. Все даты указаны по московскому времени.
